# Data placement

No private or third-party data is shipped. Place your files as follows (paths are configurable in `configs/`):

| What | Default location | Config key |
|---|---|---|
| Preprocessed privacy policies, one DOCX per application, headings styled as Word "Heading" | `data/policies/<Application Name>.docx` (e.g. `data/policies/Circlys.docx`) | `configs/applications.yaml -> policy_path` |
| PDPL Implementing Regulation text (the notebook's `IRPDPL.docx`), headings styled as "Heading" | `data/pdpl/IRPDPL.docx` | `configs/experiment.yaml -> retrieval.corpus_path` |
| (optional, later analysis only) expert ground truth workbook `PDPL Results.xlsx`, sheet `Expert Analysis` | `data/ground_truth/PDPL Results.xlsx` | `configs/experiment.yaml -> ground_truth` |

The notebook used `user pp/preprocessed/<Name>.docx`; copy those files to `data/policies/` or edit `policy_path` per application.

Sectioning rule (unchanged from the notebook): a new section starts at every paragraph whose Word style name contains `Heading`;
text before the first heading is the section "Introduction". The same rule builds the PDPL retrieval chunks.

`data/demo/` holds synthetic files generated by `python scripts/create_demo_data.py` (used by `--mock` and the tests). They are not real policies.
